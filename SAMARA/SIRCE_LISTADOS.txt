USAR
Listados de asistencia > nueva lista o Editar: aparece Datos SIRCE.
La CLAVE CURSO se guarda POR LISTADO. Puedes dejarla pendiente hasta obtenerla en SIRCE.
También puedes completarla con el botón SIRCE de cada fila sin rehacer la asistencia.
El establecimiento es fijo: 862341. RFC AGENTE STPS queda vacío para internos.
Revisa estado, municipio, fechas, área, modalidad y objetivo; las opciones son los catálogos adjuntos.
Se sugiere BAJA CALIFORNIA/MEXICALI como el ejemplo; se puede corregir al lugar correspondiente.

En el botón SIRCE puedes guardar datos, descargar Excel, descargar CSV o imprimir.
Excel/CSV tienen las 21 columnas del ejemplo, sin agregar número de empleado ni ID LISTADO.
Se incluyen los asistentes validados con firma. Se informa cuántos sin firma se excluyen.
No se exporta si faltan clave, fechas o datos personales/catalogados válidos.
Los valores 0 de documento e institución que aparecen en algunos renglones del ejemplo no están en los catálogos adjuntos: corrígelos en Personal, no se copian automáticamente.

CARGA MASIVA
1. Pulsa Cargar claves SIRCE > Descargar plantilla de claves.
2. Completa CLAVE CURSO, conservando ID LISTADO.
3. Sube el CSV o guárdalo como .xlsx y súbelo. Trata las claves como texto si contienen ceros iniciales.
4. Revisa las coincidencias y pulsa Guardar claves revisadas; se solicita confirmación.
Solo se actualizan listados existentes. No se crean ni se duplican cursos o asistencias.
Los errores o coincidencias ambiguas impiden guardar el lote. Una clave no se puede repetir entre distintos listados.
Si no hay ID LISTADO, se exige NOMENCLATURA + FECHA AAAA-MM-DD que identifiquen un listado único (INSTRUCTOR puede ayudar a distinguir).
Volver a cargar las mismas claves queda sin cambios.
